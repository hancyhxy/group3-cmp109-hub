## 5. Expected behaviour (what the automatic checks test)

Each screen line is written as the exact `utils.console` call that must produce it, in order. Prompts show what the user types next. Placeholders stand for random values:

- `{ID}`: random subject ID printed WITHOUT leading zeros, e.g. 97 or 541
- `{ID3}`: random subject ID WITH leading zeros, 3 digits, e.g. 097
- `{SID}`: random 6-digit student ID, e.g. 762740
- `{MARK}`: random mark from 25 to 100
- `{GRADE}`: grade right-aligned in 3 characters, e.g. '  P' or ' HD'
- `{AVG}`: average mark with 2 decimals, e.g. 63.50
